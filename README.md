## 🏗️ System Architecture

```
META ADS CAMPAIGN
       ↓
  Landing Page (GHL)
  [Opt-in / Lead Form]
       ↓
  GHL CRM Entry
  [Auto-tagged by campaign source]
       ↓
  Automation Workflow Triggered
  [Email + SMS Nurture Sequence]
       ↓
  Appointment Booking
  [Calendar Integration]
       ↓
  Sales Pipeline Stage
  [Tracked to Close]
```

## ⚙️ Campaign Structure

### Ad Account Setup
- Campaign objective: Lead Generation or Conversion
- Audience segmentation: Lookalike + Interest-based + Retargeting layers
- Creative rotation: 3-5 ad creatives per ad set for split testing
- Budget allocation: 70% prospecting / 30% retargeting

### Landing Page (GHL)
- Single opt-in form connected to GHL CRM via native integration
- Custom thank you page with immediate next-step CTA
- Facebook Pixel installed for conversion tracking
- UTM parameters passed into CRM custom fields

### CRM Automation on Lead Entry
1. Lead tagged with campaign source automatically
2. Assigned to sales rep based on round-robin or territory rule
3. Welcome SMS sent within 60 seconds of opt-in
4. Email nurture sequence initiated (7-touch over 14 days)
5. Internal notification sent to team via Slack/email

### Reporting
- Cost per lead tracked per campaign and ad set
- Lead-to-appointment rate tracked in GHL pipeline
- ROAS calculated against pipeline value
